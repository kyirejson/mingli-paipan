# 古籍阅读与六爻盘面优化

版本：v1.0.25，Android versionCode 26。维持纸上青山配色与原安装签名。

## 古籍阅读

- 全部 11 本书通过同一个选书入口直接选择，移除分组三屏封面轮播。
- 篇目使用完整目录选择框，避免横向标签不易发现或文字被截断。
- 工具栏固定在阅读区上方，正文在内部滚动。原页面可被正文撑到 7781 像素，现阅读区在验收设备上为 662 像素。
- 提供解说、原文、对照三种模式；字号 16–24，可保存阅读偏好。切换模式、字号不重建正文，不重新请求网络。
- 保留格局设置与调候提示。整章白话明确标识包含其他条目；只有随文旧注的底本不伪装成现代译文。
- 取文来源、命盘匹配、超时取消和沙箱边界继续沿用既有逻辑。

## 六爻盘面

- 改为六神、本卦、变卦的固定列对照，六爻由上到下按六至初排列。
- 保留六亲、纳甲、五行、世应、动爻、伏神、旺衰和用神标记；点爻切换用神，所选爻的日月关系与长生状态显示在盘下。
- 月建、日辰、日空和四柱置于盘前；完整历法、四柱旬空、节气和神煞参考置于可展开区域。
- 本卦和六个爻位的详解继续保留在盘面下方。
- 移除旧版每爻的空白状态行及大块留白样式。实际安装页的盘面依伏神数量高约 367–383 像素，可视内容高约 686 像素，六爻完整落在一屏内。
