# 造化元钥：第二批性能优化与验证

开发及测量：2026-10-29 至 2026-10-30。基线：Git `d5d3435`（第一批优化完成后的版本）。

## 本轮完成

### 首次切盘调度

- 首次访问未挂载的盘面时，先完成 Vue 挂载，经过两次 rAF 提供绘制机会，然后开始原有的 220ms 位移动画。已挂载盘面仍直接启动动画。
- 手指拖动时只更新轨道位移，不再在 `touchMove` 中同步创建相邻盘面；未准备好的页面在松手后挂载。
- 切换、触摸期间取消低优先级预热；增加切盘请求序号，快速连续选择只执行最后一次待开始的动画。
- 页面销毁和命例切换时取消尚未开始的动画。预热回调再次检查命例、当前盘及待开始动画，避免执行过期工作。
- 初始、滑动和结束位置统一使用 `translate3d`，保留现有盘面布局及 SVG 箭头几何规则。

这部分改变的是计算、挂载与动画的时序。两次 rAF 不是实际呈现帧或 GPU 上传完成的保证，也没有把计算移到 Worker。

### 题库按需加载

- 首页不再直接载入 571,175 字节的 `tiku-data.js`。题库总目录和关卡进度可先显示，第一次需要题目或提交关卡成绩时才加载数据。
- 并发读取共享一个加载 Promise；成功后复用已有数据，避免重复插入脚本。
- 网络错误、内容未就绪和超时允许重试。加载失败返回明确的 503 本地错误，不提交成绩、不回退到旧服务器。
- 题目资源仍完整保留在安装包，离线本地资源路径没有改为远程下载。

实现：`dist/static/js/lazy-assets.js`、`wzbz-native-bridge.js`、`dist/index.html`。

### 八字解说按需打开

- 原阅读器在默认八字页底部就会进入 IntersectionObserver 的预加载范围，用户未点开解说时已加载 `newguji` 页面及其依赖。
- 改为纸绿风格的“查看命局解说”入口，点击后才创建 iframe；内容及命盘数据传递继续使用原阅读器。
- iframe 的 load 事件负责发送当前命盘数据；消息只处理当前阅读 iframe 发出的内容。
- 普通排盘和对比排盘两份编译组件同时修改，销毁时解除两个 EventBus 监听及一个 window 消息监听，移除已被替代的自动可见区加载代码。

另修复一处原有错误：八字干支关系接口返回“不支持”结构时，页面继续按数组读取，出现 `map`/索引异常。现在显示“关系数据暂不可用”，并停止依赖这份缺失数据的后续处理；没有生成替代关系结果。

## 性能测量

Chrome 140.0.7339.210，独立无头浏览器，430×932，CPU 4 倍降速，关闭浏览器缓存。本地 HTTP 预览，固定出生信息为 `2026-10-29 12:00`；每侧两次重载，各顺序切盘 10 次。

下表是从发起切换到 Vue 更新完成并读取盘面边界的耗时，**不包含等待动画、220ms 动画本身及显示器呈现时间**，不能说成“用户完整切盘只需 10ms”。

| 场景 | 基线两轮，ms | 优化后两轮，ms |
|---|---:|---:|
| 首次挂载奇门 | 295.3 / 76.6 | 9.4 / 9.9 |
| 首次挂载六爻 | 386.6 / 38.0 | 14.9 / 16.1 |
| 首次挂载梅花 | 1,021.0 / 12.6 | 9.6 / 9.6 |
| 紫微，测量时已预热 | 22.9 / 3.6 | 2.6 / 7.6 |
| 重复切换五盘的更新及布局范围 | 6.6～19.6 | 1.3～13.9 |
| 点击排盘至结果宿主就绪 | 3,071 / 909 | 605 / 801 |
| 十次切盘期间 rAF 间隔 P95 | 166.7 / 16.7 | 8.5 / 8.5 |
| 同期间最大 rAF 间隔 | 1,358.4 / 133.3 | 33.4 / 50.1 |

原始数据以 [summary.json](performance-round2-2026-10-29/summary.json) 及各目录 `results.json` 为准。初次观察点两侧都已预热紫微，DOM 同为 1,328 个，因此本轮没有用 DOM 数量宣称额外收益。

限制：仅每侧 2 个样本，首轮基线与复测差异明显，JIT、网络及后台活动未完全控制。测试跨过午夜，系统日期未冻结，默认运限日期随系统时间变化。结果支持本轮优化方向，不足以承诺某个普遍提速百分比，也不能作为紫微冷首次访问性能数据。rAF 间隔不等于实际呈现帧；最大间隔仍超过 8.33ms，不能宣称稳定 120fps。

- **41/41 Node 测试通过**：原有 33 项继续通过，新增 8 项验证资源并发、失败重试、成绩写入边界、首次切盘时序、快速选择、拖动期间不挂载及监听清理。

- 浏览器真实路径通过：排盘时不加载题库/阅读器；点击后解说显示；题库异步目录、关卡和第一道题正常显示；同一文档题库脚本只加载一次；模拟脚本请求失败后返回 503，恢复请求后可成功重试，读取到首目录 63 道题。

- 通用页面检查继续通过：四种结果盘面、备份导出和移动布局、助手不可用状态。专项检查捕获运行时异常及 `console.error`，最终均为空。
