# 紫微解读整改实现与验收

本文件记录发布前的本地验收状态；正式发布信息以仓库 Releases 为准。
日期：2026-11-04。版本：v1.0.23（24）。对应[审核报告与方案](2026-11-04_紫微解读审核报告与整改方案.md)。

本轮已修复审核中复现的条件错判、宫职错位、原文串段和漏显示，并覆盖安装到原模拟器。采用原包名、签名、`https://localhost`存储来源，未卸载、清数据或改写案例结构。安装前后案例、笔记、草稿的原始字符串完全一致，包含用户后来新增的案例。

这轮是可验收的修复版，不代表所有传统断法、派别与现代白话已经完成独立专业审校。尤其不能把新增出处索引当成896条内容均已验证正确。

## 1. 已落地的主要变化

### 判式与宫职

- 廉相、同梁、紫府、日月同宫的相关增强条件，改用组合所在宫位的三方四正；武贪火铃增强条件以贪狼实际位置检查。固定上游原文件和摘要不变，本地修正由构建脚本明确应用，匹配不到原函数时构建失败。
- 马头带箭采用明确的同阴实坐、空宫借同阴和午贪化禄遇羊旁格，正文分别生成。午宫七杀遇羊不再写入不存在的天同太阴；借曜明确说明同阴在对宫。
- 删除7段已由实际落宫释义或明确变体替代的全局套话，避免错误旧文案被重新接入。
- 格局保留涉及宫位和变体；单宫双星组合改读该宫的专属文字。子女宫武曲七杀不再被套成本人的工作判断。
- 科权双会按通用四化会合口径读取合法化科，包括右弼、左辅及昌曲；在证据中列实际化曜与宫位，不再静默漏掉辅星化科。

### 原文、来源和条件

- 原文按主星、辅星、四化及斗君等独立标题分段，排除篇尾导航；命宫章另以星曜实际引介行切分，避免把提到其他星的诗句误作新标题。
- 保留162段主星上下文，新增独立归属的其他段落，共277段。古籍中的“天空”按该底本所指对应地空，并保留古称，避免引用到现代杂曜天空。
- 为基础表格、组合、细读等生成896条可定位出处记录，包含版本、条件、宫位、引用段和编辑状态。大多数仍标记“编辑参照”，不伪装成逐句审定。
- 新增7条核对过具体原句及适用条件的细读，涉及命宫、子女、疾厄、父母。现有细读共52条，十二宫均有条目，但数量与深度仍不均衡。古文只写入庙的条件，不扩大到旺；疾厄仅作传统象义阅读。
- 相同细读谓词冲突、坏出处引用、不可能的双星组合、重复主星及重复生年四化均拒绝静默使用。

### 读盘层次与内容

- 标题固定标“本命”。选择运限后，另列当前层和日期，明确本宫、三方、格局仍读本命；运限解释集中在命身运限。
- 运限四化正文包含实际化曜、运限宫职、本命承接宫、原盘亮度与星系、生年叠加标记。没有把生年四化改写为流年四化。
- 飞化按实际源宫、目标宫、化曜及人事关系解释。正文明确宫名，撤掉含混的“本宫”视角，保留忌入、忌冲及生年叠加。
- 三合共享星系基础；钦天突出已有来因标记、向心与离心结构；飞星突出宫干飞入飞出。界面列明专属进阶规则尚未接入，未宣称具备完整派别系统。
- 主文合入已命中的庙陷和四化修正；增加得、利、平的亮度说明。双辅/双煞关系显示实际同宫、对拱、三合形态。
- 补年解、龙德、大耗；杂曜共42项。长生、博士、将前、岁前分别读取真实字段，不将同名星重复计为多重事件。补命主、身主与五行局信息，区分身主和身宫。

### 界面和性能

- 五个技法入口改为窄屏两行布局，320和430宽度均完整可见。
- 十二宫分别生成自己的杂曜，单宫与通览一致；本次安装盘12宫有杂曜入口，全部显示。
- 增强、受损条件列表明确左对齐；正文保持16px，深浅色和长句均检查。
- 原段按需展开，长文随页面滚动，移除300px内层滚动限制。来源仍可继续做更深的去重和独立阅读页。
- 本命星系、格局、宫位关系和宫干飞化按命盘事实及资料对象缓存；星位变化、数组重排与资料对象改变会失效。运限独立读取。
- 已安装包WebView内10次重复解读的中位耗时约0.8ms、最高约6.8ms，仅反映本次设备的这段计算，不等同于整页帧率或真机120帧保证。
