# 题库审核与整改（2026-11-03）

基线版本：v1.0.18。整改版本：v1.0.19 / versionCode 20。

本轮审核包括题库数据结构、题干和解析一致性、命例四柱与附带日期、晋级计分、本机保存、重做、收藏、练习入口及实际页面显示。题林原始数据 35 组、1,763 条，保留全部原记录；其中 2 条四柱本身不成立的题加审核标记，停止参与新答题评分，有效题目为 1,761 条。

## 确认并处理的问题

| 问题 | 影响 | 处理 |
| --- | --- | --- |
| 晋级底层统一按 60 分 | 与界面的 90 / 80 / 70 分标准不符 | 35 关统一按实际目录门槛判定。 |
| 取最高通过关卡并把之前所有关卡标成通过 | 中间未完成的关卡可能被越级标记 | 单关按实际记录判断；连续晋级进度遇未完成关卡停止。 |
| 新一轮低分覆盖原高分 | 重做后可能失去既有通过状态 | 同时保存本次、最佳一场和累计统计；低分不取消已获得的通过状态。 |
| 失败成绩页仍显示下一关，最后一关不能重做 | 按钮含义与行为不符 | 未达到本次门槛时隐藏下一关；始终保留重做。清理不必要的先返回、再延迟跳转。 |
| 提交失败前已标答题完成，错误只写日志 | 未保存却显示已完成，部分情况下停留加载 | 保存成功后再更新解析和统计；失败保留选择、退出加载并提示重试。 |
| 连续点提交可能重复计数 | 一次答题被多次保存 | 增加提交中的防重入，并按实际选项 ID 计分。 |
| 习题目录列出未提供的题目 | 点击目录停在原页 | 将习题目录改为复用现有本地题目的 7 个难度章节、35 组练习，数量与真实题目一致；清理旧空目录数据。 |
| 旧组件部分调用忽略初始化返回值 | 练习页只显示题干，选项未渲染 | 保持原对象初始化契约，同时让接口返回题目副本，避免污染原题库。 |
| 重开练习未正确恢复答案 | 正确/错误状态和已选项不一致 | 将本机保存的答案映射回原选项 ID，恢复选择与作答次数。 |
| 快速两次收藏把闭包中的题目设成 null | 收藏状态不保存，可能报错 | 按题目串行保存最终意图；失败恢复原标记；切题不改变正在保存的目标。 |
| 滑块程序定位事件被当作向前滑动 | 跳题后可能退回上一题 | 相同页事件不再增减题号，跳题及离开组件清理旧回调。 |
| 全站作答量使用 12,850 / 11,620 等默认数 | 给人以真实在线汇总的错觉 | 移除虚构默认统计和全站收藏人数展示，只展示本机作答记录。 |
| 题目和解析纠错入口没有本地可用服务 | 用户进入无效提交流程 | 移除不可用入口，保留已有题目审核记录。 |
| 选中及正误色样式选择器未对应真实类名 | 纸绿主题覆盖了状态底色 | 补齐选中样式，纠正正误类名；提高题干、选项与解析的窄屏字号和换行表现。 |
| 百科缺少本地配套题时请求报错 | 无法区分“没有配套题”和加载出错 | 返回空题集，界面明确显示“此条目暂无本地练习”。 |

## 内容核验

- 全量检查 1,763 条记录的 ID、题干、选项、答案下标、解析、重复选项和 JSON / 运行时文件一致性。
- 按五虎遁、五鼠遁核对 345 道可识别的四柱命例（含 2 道隔离题）；其余 343 道满足年上起月、日上起时，285 个保留日期入口正排与题干四柱一致。覆盖空格分隔及带年、月、日、时字样的写法。
- `0503045`：乙年配壬子月不成立；`0504003`：乙日配丁卯时不成立，且解析数量有误。两题保留原文与审核原因，退出活动题集。
- 修复 `0604023` 的重复错误选项。
- 修正多处时间格式、日期、时辰和两处性别标记。`0305016`、`0504046`、`0701028`、`0703025` 的附带日期无法与原题四柱对应，保留题干，停用错误排盘入口并注明原因。
- 两道建禄取用题补充条件，避免把取用方法写成无条件唯一首选；两处乙木命例解析纠正“无根、无生扶”的表述；若干十神题明确以日干和地支本气为参照。
- 共 27 道题涉及内容、附带数据、格式规范或审核标记调整。逐项前后值见 [校正记录](quiz-audit-2026-11-03/content-corrections.json)。这不是“27 道答案都错”的统计。

原典参考：[《三命通会·论人元司事》](https://skqs.dazhishi.com/show_glyrrqevyz.html)、[《三命通会·论建禄》](https://www.shidianguji.com/zh/book/SK1610/chapter/1mecpymm3szzf)。本轮没有将不同流派的旺衰判断直接归为程序错误。

## 验证与边界

- 117 项 Node 回归通过，其中 19 项专门覆盖本次题库数据、门槛、重做、选项恢复、提交失败、防重复提交、收藏并发及滑块定位。
- 模拟器完成 63 题一关提交：首轮 100 分；重做 20 分后最佳成绩仍为 100 分，失败页不显示下一关。
- 35 组练习合计 1,761 道有效题均可通过实际本地接口读取，目录数量逐组匹配。
- 实际练习提交、连续收藏/取消、再收藏及页面重载后，答案和收藏状态均能恢复；检查日夜主题与 320 px 长选项显示。
- 测试仅使用模拟器中的测试作答状态，结束后还原原答题状态。命例、断事笔记及草稿单独做覆盖升级保留校验，不清理用户资料。

知识百科原文仍依赖在线来源；已抽查首篇原文 HTTP 200，部分条目没有本地配套练习。实战事件题的原始案例出处尚待补齐，旺衰、格局等流派性结论仍需要逐题复核；本轮通过的是结构、历法与流程校验，不能据此认定全部题目的学理及案例事实均已验证。
