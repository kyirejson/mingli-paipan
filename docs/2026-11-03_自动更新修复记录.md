## 发布流程改进

新增 `scripts/publish-release.py`：不带 `--publish` 只做本地校验与生成清单；带该参数才修改 GitHub Release。检查 APK 原生包名、版本、签名、对齐、ZIP 完整性和包内版本信息，防止清单与实际安装包不一致。

发布时先校验或上传 APK、校验清单内容与公开下载，再设置正式 latest，最后核对 installed updater 所使用的最新正式版接口。已有附件不一致时停止，不删除或覆盖原安装包。GitHub 凭据通过已有凭据管理器读取，仅留在进程内存中。所有构建和验证临时文件默认保留在 D 盘工作区，短期预检副本在结束时清理。

新增 `tests/test_release_contract.py` 的 8 项测试通过：缺失 update.json、预发布阻挡、不一致 APK、不一致清单、公开清单失败、上传/验证/切换通道顺序、重复发布及错误下载地址。

## 使用与复现

手机打开“设置 → 版本更新 → 检查更新”，应发现 v1.0.14，再下载并按系统提示确认安装。后台检查仍受原有时间间隔和安卓省电策略影响，手动检查可主动发起请求。

发布工具命令：

```powershell
python -m unittest discover -s tests -p test_release_contract.py -v
python scripts/publish-release.py --version 1.0.14 --version-code 15
python scripts/publish-release.py --version 1.0.14 --version-code 15 --publish
```

发布地址：[v1.0.14](https://github.com/kyirejson/mingli-paipan/releases/tag/v1.0.14)。仅提交源码不会触发手机安装，今后每次发布都应使用完整的更新清单和通道检查流程。
