# 安装、更新与数据

[返回项目介绍](../README.md)

## 下载与安装

打开[最新正式版](https://github.com/kyirejson/mingli-paipan/releases/latest)，在 Assets 下载 APK。在安卓手机打开文件，按系统提示允许当前下载来源安装。当前提供 Android 安装包，未分发正式 iOS 版本。

发布页还提供 `update.json` 与 `SHA256SUMS.txt`，用于应用检查更新与文件校验。版本内容以各次 Release 说明为准。

## 更新与保留资料

APP 内进入“设置 → 版本更新”检查，下载后由系统确认安装。请覆盖安装，保留应用包名、签名和本地数据；不要先卸载、清除数据。

- 同签名 v1.0.13 及后续版本可以直接覆盖升级，不必依次安装中间版本。
- 从 v1.0.14 及更早版本首次升级前，先导出已有资料。
- v1.0.7 及更早版本采用旧签名，需要单独迁移。
- 仍存在的旧缓存可在“设置 → 数据备份与恢复 → 找回旧记录”尝试合并。

命例、笔记等主要保存在本机。应用私有保护副本不能代替卸载前的外部备份；卸载可能删除资料。

## 阅读与联网

八字古籍部分章节按需从公开来源读取，需要网络及来源站可用。八字基础排盘接口等也有联网依赖。古籍提供原文、原有评注和已收录白话；《天元巫咸》当前提供随文旧注，没有独立现代译文。

紫微预编解读和六爻三书解读使用已实现的程序规则与资料条目，尚未覆盖全部流派技法或三书全部章法。独立的紫微助手需配置可用模型服务；本机开发代理不是面向外部用户的远程服务。

## 问题反馈

请在[Issues](https://github.com/kyirejson/mingli-paipan/issues)提供应用版本、手机型号、操作步骤和出现问题的位置。反馈图片时隐去姓名、出生信息、笔记与其他个人资料。资料来源及规则范围见[开发文档](DEVELOPMENT.md#资料来源)。
