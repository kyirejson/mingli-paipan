## 新确认的外部依赖

浏览器中全面禁止旧域名请求会使首页无法继续，已定位为 `https://bzapi3.iwzbz.com/getbasebz8.php`。它是当前八字基础排盘的实际依赖，恢复该精确接口后，创建命例和四个其他体系结果页通过检查。首页已说明基础排盘需要联网并发送起盘信息。

**这项依赖尚未消除。** 要彻底本地化，必须实现并验证原接口所返回的完整八字结构，不能简单拦截，也不能只拿四柱代替整份返回数据。

## 开发与构建

测试无需新增 Node 依赖：`npm test`，或执行 `package.json` 中的 Node 命令。

浏览器验收使用已启动的独立 Chrome CDP（默认端口 9330）和预览服务（默认 localhost:9988）：`node tests/browser-smoke.mjs`。可通过 `ZAOHUA_CDP_PORT` 与 `ZAOHUA_PREVIEW_URL` 更改；不再依赖开发目录外的历史命例文件。

```powershell
pwsh -File scripts/build-release.ps1 -Version 1.0.9 -VersionCode 10
```

脚本需要 `build-inputs.json` 锁定的基础 APK、Apktool、现有 Java/Android Build Tools，以及单独保管的签名和密码。默认工作目录是 `D:\zaohua-release-work`，所有临时构建数据在 D 盘。脚本不会覆盖已有同名发布文件。它不是从原始安卓源代码进行的 Gradle 构建。
