# 数据保护、名人库与排盘界面修复

2026-11-03（Asia/Shanghai）。用户明确说明从 v1.0.13 在 APP 内直接覆盖升级到 v1.0.14，没有卸载或清除数据。本轮同时处理命盘保留、名人库资料、古籍排版、紫微比例四项请求。新版本为 v1.0.15（versionCode 16）。

## 命盘与笔记保留

比较已发布的 v1.0.13/v1.0.14：包名、签名、WebView 地址配置、命盘存储键，以及旧本地存储适配代码相同。未发现这次发布修改了这些配置，也不能仅凭用户的现象认定更新程序执行过删除。当前没有连接用户手机，不能声称已找到该手机的唯一原因或找回全部旧盘。

在隔离安卓模拟器内，旧版刚写入浏览器存储后马上覆盖安装，可复现资料未读回；另一次先确认旧版冷启动可读，再覆盖升级，资料保留。这表明仅靠浏览器存储且不确认落盘，缺少足够的更新保护。该实验不是用户手机日志。

新增保护机制：

- 保持 `com.wzbz.bazi`、`https://localhost`、现有 `wzbz_local_userlist_v14` 等存储键不变。这个 v14 后缀是既有数据结构标识，不随 APP 小版本更新换键。
- 在应用私有 SharedPreferences 中保存独立于 WebView 的当前/前次保护副本；使用同步 commit 确认写入，后台线程处理磁盘操作。没有提供清空该备份的原生接口。
- 启动时先读取和合并保护副本，再启动 Vue。按 GUID 保留记录，冲突内容另存。每个数据项记录修订序号，避免刚退出时较旧的浏览器副本压过较新的原生副本；不依赖手机时钟判断新旧。
- 保存命例和笔记接口等待保护写入；草稿等直接写入进行合并保护。下载更新及点击安装之前均强制写入并读回核对，未完成则阻止继续安装。
- 拦截清空、删除受保护存储键及覆盖掉已有命盘的写入。旧永久删除接口保留原行并标记删除；不会在升级时物理移除原记录，也不会自动复活用户已标记删除的命盘。
- 导入备份改为合并，保留本机记录；仍兼容旧 v1 备份。新 v2 备份补入合盘、相关记录及冲突原文。事务中断时回滚。
- “数据备份与恢复”增加“找回旧记录”，由用户决定是否合并历史缓存；可能包含曾排过但未保存的盘，因此不自动塞入记录。原始保护资料可单独导出，损坏条目不会被默认样例替换。
- 原生读写需要主页面闭包内的随机令牌并核对主页面地址，防止远端古籍 iframe 直接读取保护副本。未将密钥、登录会话写入备份。

保护从本版起生效，不能凭空恢复已经物理清除且没有缓存或备份的旧记录。应用私有备份用于覆盖升级，卸载和清除应用数据仍需外部备份。首次从尚无原生保护的旧版升级，建议先导出一份现有资料。

## 名人库

此前整改将名人接口的 CSV 返回值设为空字符串，导致界面资料消失。原始资料仍在审计快照中，已将 58 条原记录完整恢复为包内按需加载资源；断网也可读取，读取失败可以重试。没有把原始内容当成已考证的出生事实。

资料继续保留未知时辰 `**`，标明旧版资料未经逐条核实。旧记录 `isOpenLiuNian=0` 的年份属于排盘参考坐标，界面沿用时代与身份说明，不冒充真实历史生年；未猜改这些日期或补填时辰。来源与标准化摘要见 `dist/static/data/celebrity-legacy.source.json`。

## 古籍排版

确认为阅读页资源解析顺序错误：`base` 原来插在 head 末尾，排在相对 CSS/脚本链接之后，导致样式未按正确地址加载。实际模拟器截图显示按钮、图标无样式堆叠。修复为在 head 开始处插入资源基址，样式恢复正常；添加了链接顺序回归检查。

保留旧版书封、调候区域、章节横向目录、原文/译文/对照的结构，收起正常状态下额外的说明行，处理横向溢出和不必要的最低高度。保持日夜配色与来源署名、访问提示，不恢复旧版对访问标记、水印及署名的改写。

## 紫微比例

原布局将命盘拉满剩余高度，盘面长宽比随手机长宽和运限区域变化。三合、钦天、飞星改为同一 4:5 盘面比例；大限和流年仍保留。小屏允许页面滚动，不压扁宫格；宽屏限制最大宽度。SVG 仍按实际宫格尺寸绘制，不额外缩放箭头。

同时修正中央自化图例与八字大运文字叠放，将图例放回文档流；中央资料较多时允许内部滚动。长姓名标题增加省略显示。

## 验证与证据

最终检查记录放在 [data-preservation-2026-11-03](data-preservation-2026-11-03/)。包含 Node 回归、安卓覆盖/退出检查、最终界面截图、实际比例和包内一致性摘要。`*-preview.png` 是中间预览；`*-final.png` 才是最终安装包检查。`classics-layout.png` 为样式未正确加载的修改前复现，不应当作最终效果。

测试使用隔离模拟器和人工构造的测试命盘，未接触用户手机资料，未执行卸载或清除应用数据。原模拟器数据镜像及测试快照保留在 D 盘。确实发现并修复了开发候选包中“旧浏览器副本优先导致笔记回退”的问题，失败候选包没有发布。

新原生保护插件源码位于 `native/src/com/wzbz/bazi/DataVaultPlugin.java`，构建脚本将其编译到独立 classes2.dex，保留原 classes.dex。编译用 Capacitor API 存根不装入 APK；运行时使用原外壳既有实现。原始完整 Gradle 工程仍未恢复，不能把新增插件源码称为恢复了全部安卓工程。

发布预检新增存储来源检查和保护插件/资源完整性检查，避免之后误改协议、主机、应用标识或漏装保护组件。签名继续沿用现有新签名，用户直接覆盖升级即可。

发布工具另外修正了 GitHub 草稿附件临时地址的校验与草稿按标签查询 404 时的续传定位，使用同一草稿继续上传，不覆盖已校验安装包。正式发布后仍严格要求真实版本标签地址。发布协议测试最终为 12 项。
