# 界面显示与可读性整改（2026-11-03）

本轮以模拟器中的 v1.0.17 为基线，整改后版本为 v1.0.18 / versionCode 19。覆盖首页、时间选择、八字四个标签页、紫微三种盘式、奇门、六爻、梅花、记录、题库、设置及五运六气。沿用“纸上青山”的纸绿风格。

## 问题与处理

| 发现的问题 | 原因与整改 |
| --- | --- |
| 日期滚轮未选中行几乎看不见 | 遮罩与文字叠加变淡，夜间还混入旧色值。去除渐隐遮罩，使用 16 px 普通行、18 px 选中行和浅底选中提示。 |
| 八字的列标题、五行文字偏淡，表格字小 | 旧设置会覆盖五行变量。保留用户保存的颜色，在浅色主题中加深显示；夜间改用清晰的五行色。表格正文由 11 px 调到 13 px，列标题提高对比度。 |
| 六爻神煞、旺衰和参考依据过小 | 原有 8–11 px 字号及窄屏再次缩字叠加。提高辅助文字字号并移除过时缩字规则；状态可换行。 |
| 六爻窄屏本卦与变卦爻线错位 | 左侧用神、五行换行后，垂直居中使两侧爻线高度不同。将六亲纳甲与角色、五行分层排布，爻线与首行对齐。 |
| 夜间六爻用神、原神、忌神等辨识困难 | 原为固定深蓝、深绿、黑色。新增日夜两组角色文字色，保持各角色的区别。 |
| 梅花卦名和关系表字号过小，阳爻中间有细缝 | 卦名提高至 14 px，关系表 13 px，类象辅助字 12 px；阳爻以单个完整线段显示，避免两个圆角线段拼接的缺口。 |
| 紫微中央文字被箭头穿过 | 中央文字原位于箭头层之下。提高文字层级，并仅为文字块设置纸色底，保留空白区域的连线和原有箭头坐标。 |
| 紫微小屏会继续缩至 6–8 px | 旧短屏规则与固定比例盘面不再适配。移除短屏继续缩字规则，中央信息允许滚动；保留 4:5 命盘比例、大限流年独立行。 |
| 紫微四化高亮的白字不够清楚 | 箭头和文字共用较亮色值。单独加深文字徽标的底色，箭头本身的四化计算和配色保持原样。 |
| 十二宫总览信息密集 | 新增“宫位详读”，按当前盘式列出星曜、亮度、四化、大限、流年、小限及十二神等。十二宫均可切换，正文 16 px、说明 13 px；不保存或修改命盘。 |
| 记录页夜间筛选、索引和分组偏淡，存在无内容圆块 | 修正筛选背景和图标亮度、索引及分组文字色；隐藏没有内容的头像占位。 |
| 题库说明小、夜间关闭状态开关看不到圆点 | 说明文字统一提高到 12 px；关闭状态使用明亮开关圆点，开启状态保留深色圆点。五运六气的画布背景同时跟随纸绿主题。 |

## 验证

- 98 项 Node 回归通过，包括新增的十二宫详读数据完整性、宫位切换及不改写会话校验。
- 13 项更新协议、9 项构建生命周期检查通过。
- 日间/夜间 28 个页面与状态的截图和文字指标检查，另查八字信息、细盘、笔记、参考弹窗及五运六气。日主、阴阳、旺衰共 6 次弹窗检查未发现横向裁切；六爻 6 行在两种主题下的两侧爻线纵向差值均为 0。
- 320 / 360 / 412 CSS px、三种紫微盘式、两种主题，共 18 种布局、216 次宫位详读切换检查。检查盘面 4:5 比例、弹窗宽度和正文可读尺寸。
- 最终包使用相同应用标识、签名和存储来源，采用覆盖安装。命例、笔记、草稿的原始测试值与原生保护副本在最终包覆盖后再次逐项核对通过。
- 自动文字对比度只用于筛查：图片、伪元素和箭头不会由普通 DOM 文字检测完整覆盖。题库关卡编号的绿色背景由伪元素绘制，自动结果会误判为白字低对比度，已通过截图核实。

紫微总览保持十二宫的紧凑布局；查看密集星曜和年龄列表时，使用“宫位详读”获得完整大字信息。较窄屏幕允许纵向滚动，不继续把文字压小。测试范围为当前模拟器和所列宽度，不代表已经检查所有实体手机及系统字体缩放组合。
