## 修改内容

| 原编号 | 本次实施 | 待界面验收 |
| --- | --- | --- |
| UI-01 | 紫微采用命盘、运限、模式栏三行布局，取消命盘 432 px 最小高度和模式栏压盖；默认常显大限、流年，三合流月/流日/流时仍可展开。展开状态在换命例时重置 | 320/360/430 宽下三种紫微盘同屏；点击大限/流年不跳动；密集宫位内容及红线可读 |
| UI-02 | 以原设置管理的 body 主题为来源，同步 html 主题入口及原生控件配色；助手、备份控件、紫微夜间星曜与时间滚轮遮罩使用主题颜色 | 日/夜/跟随系统实际切换；五盘、阅读弹窗、题库、记录和设置配色 |
| UI-03 | 笔记保存栏改为正常文档流，取消在正文上方驻留；原有草稿与保存逻辑保留 | 短屏和真实键盘打开时编辑内容、光标与保存按钮均可正常操作 |
| UI-04 | 设置标题和备份按钮作为同一行，排盘偏好独立占第二行；明确入口、标题、按钮的字体与样式 | 窄屏无逐字竖排，备份及偏好入口正常 |
| UI-05 | 五盘容器宽度变化后，在最终布局帧重新测量旧八字滑块；连续请求合并，销毁时取消观察和待执行工作 | 宽→窄→宽、隐藏后返回、切换八字子页后时柱仍在屏内 |
| UI-06 | 梅花爻线按钮由 5 px 提高为 24 px，爻线笔画仍为 5 px；取消可能越界重叠的伪元素点击区 | 手指逐爻点选准确，六个爻位及详情对应正确 |
| UI-07 | 记录姓名文本使用弹性布局和省略号，性别不参与收缩 | 合法长姓名与默认示例名称不再硬裁断 |
| UI-08 | 司令原始占位星号显示为“暂无数据”；真实内容与隐私遮罩分别保留 | 正常值、占位值和隐私状态显示符合语义 |
| D-01 | 两份旧排盘组件发送主题消息前检查 iframe 的 contentWindow，保留有效窗口的正常消息 | 打开过排盘、离开页面后切换主题无运行时异常 |

紫微密集宫位的字形碰撞、Android 字体放大和小字阅读负担仍需设备确认。此次调整短屏的宫位辅助信息间距，未据此宣称 R-01/R-02 已解决。没有改动排盘计算引擎。
