# 造化元钥 v1.0.15

发布日期：2026-11-03。Android versionCode：16。新签名正式发布版。

## 本次修复

- 增加命盘、笔记、草稿等资料的独立原生保护副本，启动先恢复检查，下载与安装更新前强制写入并读回核对。
- 用修订序号判断数据新旧，修复立即退出后旧浏览器副本覆盖新笔记的问题；拦截清空、删键及覆盖掉已有命盘的写入。
- 备份恢复改为合并；增加“找回旧记录”和原始保护资料导出。冲突内容保留，旧存储键不随 APP 版本更换。
- 恢复 58 条旧版名人及古籍命例，包内读取、按需加载。明确资料未经逐条核实；保留未知时辰，参考年份不作为真实生年。
- 修复古籍相对样式资源的基址插入顺序，恢复书封、章节和正文的原有排版，保留来源与访问提示。
- 三合、钦天、飞星统一为固定 4:5 盘面比例，小屏滚动展示，避免拉伸；修复中央图例与大运文字叠放及长标题溢出。

## 数据与升级

v1.0.13/v1.0.14 与本版同签名、同包名及同一 WebView 地址，直接覆盖安装，不需要卸载或清除数据。

原生独立保护从本版开始生效。首次从旧版升级前，请先在“设置 → 数据备份与恢复”导出一次现有资料。已经不显示的旧盘可在升级后尝试“找回旧记录”；仅在旧缓存或备份仍存在时可恢复，不能凭空恢复已物理清除的数据。

应用私有保护副本用于覆盖升级，卸载或清除应用数据仍会影响本机资料，请另存外部备份。旧签名 v1.0.7 及以前不能直接覆盖新签名版本，需要单独迁移，本说明中的直接覆盖针对同签名版本。
