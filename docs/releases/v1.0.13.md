# 造化元钥 v1.0.13

发布日期：2026-10-31。Android versionCode：14。新签名预发布版。

## 更新内容

- 调整紫微命盘与运限布局，大限、流年默认常显，三合盘的流月、流日、流时保留展开入口。
- 统一日夜主题入口，调整助手、备份和时间滚轮配色，并处理离开排盘页后切主题的 iframe 异常。
- 取消笔记保存栏对正文的悬浮遮挡，重新排列设置页标题、备份及排盘偏好入口。
- 处理窗口宽度变化后的八字滑块测量；扩大梅花逐爻点击区域，保留原爻线笔画。
- 为记录列表长姓名增加省略显示，司令占位星号改为“暂无数据”。
- 同步此前未发布的本地改进：四柱本地反查与公历/农历/四柱时间选择界面、题库与阅读资料按需加载、紫微运限缓存及切盘预加载控制、本机数据备份和保存可靠性改进。

## 安装与兼容

新签名 v1.0.8 和本地 v1.0.9～v1.0.12 与本版使用同一签名，可覆盖升级，建议升级前备份重要记录。

v1.0.7 及以前的旧签名版本不能直接覆盖安装：请先备份，再卸载旧版并安装本版；卸载会删除本地应用数据。本版沿用新签名预发布通道，不替换旧签名正式更新通道。

## 验证范围

59 项 Node 回归及 2 项 Python 代理检查通过，APK 签名、对齐和 10 个已修改资源的包内一致性核对通过。安装包内计算引擎与本地 v1.0.12 相同。

修复后的截图、触控、真实键盘和 Android WebView 验证尚未完成，不将本轮界面调整宣称为全部通过真机验收。紫微助手的手机远程服务仍未开通。

仓库根目录现在是当前开发工程；旧 recovered-web 目录由当前 dist、scripts、tests、docs 替代，旧提交历史及 v1.0.1 历史说明保留。10 月 30 日的审核、实施记录描述的是发布前状态。
