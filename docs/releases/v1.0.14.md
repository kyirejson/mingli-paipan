# 造化元钥 v1.0.14

发布日期：2026-11-03。Android versionCode：15。新签名正式发布版。

首次上传时的预发布标志和缺失更新清单导致 v1.0.13 无法发现本版；现已补齐 Release 附件 `update.json`，并设为 latest 正式版。APK 文件及签名不变，v1.0.13 用户可在“设置 → 版本更新”重新检查、下载并确认安装。

## 更新内容

- 修复八字古籍的两处乱码和《五行精纪》日时目录检索错误；无匹配条目不再生成错误的阅读请求。
- 修复相同格局下切换命例仍显示旧资料、快速换书时旧请求覆盖新正文的问题。
- 正文加载增加完整超时、错误提示和重试；切书、离开页面时清理旧请求、计时器与阅读资源。
- 等待真实命盘信息后再显示参考，移除初始示例分栏和空格局时的假定结果。
- 统一古籍日夜阅读配色；修复“格局参考”在旧会员字段为零时点击无反应的问题，使用现有本地格局设置入口。
- 清理《天元巫咸》第二轮无法命中的重复目录，保留原六十甲子编号。
- 暂停使用《五行精纪》中 6 个源站标题存在疑误的日时条目，向相关日柱显示说明，其他资料及服务编号保持不变。未猜写替代原文。
- 保留源站访问提示、署名和水印，收紧内嵌网页的消息来源判断。

独立书库没有恢复。古籍正文仍依赖原在线服务，本次没有打入整部离线书籍。

## 安装与兼容

本版与新签名 v1.0.8～v1.0.13 使用同一签名，可覆盖升级；建议安装前备份重要命例和笔记。

v1.0.7 及更早的旧签名版不能直接覆盖安装，卸载会删除本地应用数据，须先完成备份。本版作为仓库 latest 正式发布，因此旧版也可能看到更新信息，但原生签名校验仍会阻止不兼容的覆盖升级；旧签名用户需要单独迁移。新签名 v1.0.13 用户无需卸载。
